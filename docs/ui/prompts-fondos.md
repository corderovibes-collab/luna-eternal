# Prompts de los fondos por pantalla

Cada pantalla del PokePad puede tener **su propio fondo completo**. Es lo que
hace que cada una parezca diseñada y no una plantilla rellenada.

## Antes de generar

| | |
|---|---|
| Tamaño | **1920 × 1080**, igual que el `pokepad.png` que ya hiciste |
| Composición | **La misma**: marco, pantalla grande en el centro, dos paneles laterales |
| Qué cambia | El **color** del marco y un emblema pequeño en la pestaña de arriba |
| Dónde va | `Downloads/interfazpokepad/fondo_<nombre>.png` |

> **La composición no se toca.** El mod mide dónde cae la pantalla azul del
> `pokepad.png` original y usa esa medida para todos. Si en un fondo la
> pantalla queda más arriba o más estrecha, la rejilla no encajará.

> **No hace falta hacerlos todos.** Lo que falte usa el común. Genera
> `fondo_cazas.png` primero, lo monto, y si te convence sigues.

Después: avísame, o lanza tú:

```
python tools/importar_pad.py
python tools/gen_resourcepack.py
```
